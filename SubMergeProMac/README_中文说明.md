# SubMergePro Mac 版说明

这是按照你原来的 Python 软件功能，重新整理出来的一套 `Swift + SwiftUI` 版本源码结构。

## 你最关心的几个文件

`Views/ContentView.swift`
这个文件只负责页面。
你以后如果只想改按钮位置、表格外观、颜色、圆角、字大小，主要看这个文件。

`ViewModels/SubMergeViewModel.swift`
这个文件负责“点按钮后做什么”。
比如添加视频、批量合成、选择字幕、选择输出目录，都是这里控制。

`Services/FFmpegService.swift`
这个文件负责真正调用 `ffmpeg` 合成视频和字幕。

`Services/SRTConverter.swift`
这个文件负责把 `srt` 转成 `ass`，这样就能支持更好的字幕样式。

`Services/SubtitleStyleBuilder.swift`
这个文件负责把你界面上选的字体、字号、颜色、描边这些设置，变成 FFmpeg 能识别的字幕样式。

## 这版已经覆盖的旧功能

1. 添加多个视频
2. 添加整个文件夹里的视频
3. 自动匹配同名字幕
4. 单个视频合成
5. 批量全部合成
6. 统一设置视频格式、分辨率、比特率、帧率、编码器
7. 统一设置字幕字体、字号、颜色、描边、位置
8. 合成后打开输出文件位置
9. 显示视频基本信息

## 和旧版相比，新的结构更清楚

旧版 Python 是页面和功能写在一起。
新版我已经帮你拆开了：

1. `Views`
只管长什么样。

2. `ViewModels`
只管按钮逻辑和数据变化。

3. `Services`
只管真正处理视频和字幕。

## 你接下来怎么用

你可以在 Xcode 里新建一个 `App` 类型的 macOS 项目。
然后把这些 Swift 文件分别拖进去。

这个程序依赖 `ffmpeg`。
Mac 上如果还没有安装，可以先执行：

```bash
brew install ffmpeg
```
