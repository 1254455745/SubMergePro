# Roadmap

This roadmap is intentionally lightweight. It is a place to keep the next useful improvements visible without over-planning the project.

## Short Term

- Add README screenshots and a short demo GIF.
- Add drag-and-drop import for videos and subtitle files.
- Improve progress reporting by parsing FFmpeg progress output more precisely.
- Add a clearer FFmpeg missing/install prompt inside the app.
- Add sample files or fixture instructions for manual QA.

## Release Quality

- Add Developer ID signing and notarization for public downloads.
- Add a release checklist to each GitHub Release.
- Consider shipping separate unsigned development artifacts and signed user-facing artifacts.
- Add crash/log collection instructions for bug reports.

## Product Polish

- Save and restore recent export settings.
- Add preset management for subtitle styles.
- Add batch conflict handling when output files already exist.
- Add more explicit cancellation and retry states.
- Improve accessibility labels and keyboard navigation.

## Larger Ideas

- Optional bundled FFmpeg distribution with full license documentation.
- Auto-update support.
- Queue controls for pausing and resuming batch jobs.
- Export templates for common social video formats.
