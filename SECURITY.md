# Security Policy

## Supported Versions

The latest released version is supported.

## Reporting a Vulnerability

Please do not publish security-sensitive details in a public issue.

Report vulnerabilities by opening a private security advisory on GitHub, or contact the repository owner directly if private advisories are not enabled.

Useful details to include:

- A short description of the issue
- Steps to reproduce
- Impact
- macOS version
- SubMergePro version
- Whether FFmpeg is bundled or installed separately
